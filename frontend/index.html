Development Lifecycle (12 Stages)

1. Problem Definition Identified the need for ML-driven budget optimization in social media marketing campaigns.
2. Requirement Analysis Defined core parameters (Age, Budget, Geography) and target platforms (Instagram, LinkedIn, etc.).
3. Data Balancing Generated synthetic datasets using Python libraries (NumPy, Pandas) to simulate real-world advertising data.
4. Data Cleaning Balancing the dataset using real life logics
5. Exploratory Data Analysis (EDA) Visualized correlations between budget, audience demographics, and platform conversion rates.
6. Feature Engineering Encoded categorical variables (One-Hot Encoding) and scaled numerical inputs for model compatibility.
7. Model Selection Evaluated multiple algorithms (logistic regression) before selecting Random Forest for highest accuracy.
8. Model Training Trained the classifier on 80% of the dataset and tuned hyperparameters for optimal performance.
9. Model Evaluation Validated model using the testing set, achieving 94.8% accuracy and high F1-scores.
10. Backend API Development Built a RESTful Flask API to expose the model as a usable web service.
11. Frontend Interface Design Developed a responsive HTML/CSS/JS interface for real-time user interaction.
12. System Integration & Testing Connected frontend to backend, performed integration testing, and finalized deployment structure.
